Ikuti langkah berikut untuk update sistem iMersFireship ke versi terbaru yang sudah mendukung:

1

LANGKAH 1 — Hapus Library Lama Uninstall

  1. Buka Google Sheets project iMersFireship Anda
  2. Klik menu: Extensions → Apps Script
  3. Cari menu Libraries di sidebar kiri
  4. Cari library bernama: iMersEngine
  5. Klik ikon titik tiga (•••)
  6. Pilih: Remove
Library lama berhasil dihapus
2

LANGKAH 2 — Pasang Library Baru Install

  1. Masih di menu Libraries
  2. Klik tombol: + Add a library
  3. Masukkan Script ID berikut:
    1atax9n3DszQyRqKq9c7TA3eb6C9tLwiclXnYVhcoe9UxMPQZPEcC0HzE Copy
  4. Klik Look up
PENTING — IDENTIFIER WAJIB SAMA

Pada kolom Identifier, isi dengan:

iMersEngine
  • Jangan diubah
  • Harus sama persis
  • Huruf besar kecil sesuai
3

LANGKAH 3 — Pilih Version & Add Select

  1. Pada bagian Version, pilih versi terbaru
  2. Klik tombol Add
Library baru berhasil dipasang
4

LANGKAH 4 — Update Deployment Deploy

  1. Klik tombol Deploy
  2. Pilih Manage Deployments
  3. Edit deployment lama atau buat deployment baru
  4. Pastikan menggunakan source terbaru
  5. Klik Deploy
